# Vue.js Course Practice

This repository tracks my progress through Maximilian Schwarzmüller’s Vue.js course. It contains code-along examples and my solutions to the course assignments. [Vue - The Complete Guide (incl. Router & Composition API) on Udemy](https://www.udemy.com/course/vuejs-2-the-complete-guide/)

**Status:** In progress. I’m adding examples and assignments as I work through the course.

## Running the Examples

Each example uses HTML, CSS, and JavaScript and loads Vue 3 from a CDN.

1. Clone or download this repository.
2. Open the `index.html` file in the folder you want to explore. For a first example, open `gs-01-starting-project/index.html`.
3. Keep an internet connection available so the browser can load Vue from the CDN.
